# PLAN — agent-net-doctor v0.1.0

## Одна фраза

Тот, у кого Claude Code или Codex в WSL2 или Ubuntu висит на «Waiting for API response»,
за минуту узнаёт, на каком участке рвётся связь и что поменять. Не нужно гадать
«это VPN» и переустанавливать.

## Вертикальный срез

Один сценарий от начала до конца:

1. Человек скачивает `net-doctor.sh` по README и запускает `bash net-doctor.sh`.
2. Скрипт определяет среду: WSL2 или Ubuntu без WSL, какие агенты стоят.
3. Читает режим сети WSL и прокси-переменные. Меряет:
   - прямой доступ и доступ через прокси;
   - серию подключений к прокси-порту против контрольного порта внутри WSL;
   - эндпоинты установленных агентов;
   - DNS/IPv6 и TLS.
4. В конце печатает одну строку «где рвётся» и одну «что поменять».
   Код выхода: 0 здоров, 1 найдена поломка, 2 среда не поддерживается.
5. Сетевые адреса в выводе скрыты, так что вывод можно показать на экране
   или вставить в issue.

Как проверить, что сработало: вердикт совпал с тем, что человек потом поменял,
и агент перестал виснуть. На здоровой сети вердикт «сеть здорова».

## Чего нет в первой версии

- macOS: вежливый отказ и код 2. Поддержка в v0.2, если найдётся тестер с Mac
- Windows PowerShell
- проверка MTU
- самостоятельная починка: скрипт только читает и меряет
- настройка VPN-клиентов
- серверная сторона Anthropic и OpenAI: если сеть здорова, скрипт так и говорит
